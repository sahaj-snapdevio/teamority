# Screenshots

Drop product screenshots here, then reference them from the root [README.md](../../README.md).

Expected files (referenced by the README once added):

| File | What to capture |
|------|-----------------|
| `board.png` | A list's **Board** view with a few tasks across statuses |
| `list.png` | The same list in **List** view, grouped by status |
| `sprint.png` | A sprint with story points and the burndown |
| `task.png` | Task detail: description, assignees, comments, attachments |
| `mobile.png` | Any view at a narrow (~390px) viewport |

Guidelines:

- **Use demo data only.** Never capture real user names, real email addresses, or
  customer content — these images are published in a public repository and cannot
  be removed from git history afterwards.
- Prefer light mode for consistency, 1600px wide or larger, PNG.
- Keep each file under ~500 KB so clones stay small.

Once the files exist, replace the placeholder table in the root README with real
image embeds, e.g. `![Board view](docs/screenshots/board.png)`.
